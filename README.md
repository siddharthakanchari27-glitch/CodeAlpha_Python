# CodeAlpha_Python
CodeAlpha Hangman Game

Project Overview

The Hangman Game is a simple, text-based Python game developed as Task 1 of the CodeAlpha Python Programming Internship.

Features

- Random selection from five predefined words
- Letter-by-letter word guessing
- Maximum of six incorrect guesses
- Input validation
- Displays guessed letters and remaining attempts
- Win and game-over messages

Technologies Used

- Python
- Random module
- While loops
- If-else statements
- Strings and lists
- Functions

How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run "python hangman.py" in the terminal.
